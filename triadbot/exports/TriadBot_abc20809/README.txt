Portable personal runtime export. Run INSTALL.bat with Python 3.11 x64, then import bot.bot.toml into RLBot v5 for offline 1v1. Three original networks remain separate; this is not one merged .pt/.lt.
One model controls each 8-tick decision. Waiting models gain probability; recent/frequent selections lose probability. Selection statistics print to the bot log. All models stay frozen.
Ripple 276->90 projection and its held-control queue approximation can lose skills. Switching experts can disrupt mechanics; no strength gain is claimed.
